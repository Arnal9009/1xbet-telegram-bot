# 1xBet TopUp & Withdraw — Telegram Bot

Telegram-бот для пополнения баланса и вывода средств с аккаунта 1xBet. Поддерживает три языка (RU / EN / KG), проверку капчей, deeplink-переходы в банковские приложения и систему операторского подтверждения через закрытый чат.

---

## Быстрый старт

```bash
git clone https://github.com/<your-repo>/1xbet-telegram-bot
cd 1xbet-telegram-bot
pip install -r requirements.txt
cp .env.example .env   # заполните переменные
python bot.py
```

---

## Переменные окружения (`.env`)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота из @BotFather |
| `ADMIN_CHAT_ID` | ID закрытой группы операторов (отрицательное число) |
| `OPERATOR_USERNAME` | Username оператора для связи, например `@topkassa_pomoshnik` |
| `MIN_TOPUP` | Минимальная сумма пополнения (по умолчанию: `100`) |
| `MAX_TOPUP` | Максимальная сумма пополнения (по умолчанию: `100000`) |

---

## Роли и доступ

### Пользователь (клиент)
- Взаимодействует с ботом в личных сообщениях
- Проходит капчу, вводит ID 1xBet, сумму, выбирает банк
- Отправляет чек (фото / PDF) или QR-код банка
- Получает уведомление о статусе заявки

### Оператор
- Получает заявки в закрытую группу (`ADMIN_CHAT_ID`)
- Подтверждает или отклоняет заявки inline-кнопками прямо в чате
- Бот автоматически уведомляет клиента о решении

> Чтобы стать оператором — добавьте бота в закрытую группу и назначьте его администратором с правом отправки сообщений.

  Ошибка → просит ввести корректную сумму.

Шаг 4. Выбор банка
  [MBank] [Bakai] [Optima Bank]
  [MegaPay] [Simbank] [DemirBank] [O!Bank]

  ┌──────────────────────────────────────┐

  │ 🏛 Банк: MBank                       │
  │ 🆔 ID 1xBet: 12345678               │
  │ ⏳ У вас 15 минут на оплату          │
  │ 📎 После оплаты отправьте чек        │
  │ [💳 Оплатить в MBank]  ← deeplink   │
  └──────────────────────────────────────┘

Шаг 6. Пользователь присылает чек (фото или PDF)
  Бот: «Чек принят, заявка передана оператору (5–15 мин)».

Шаг 7. Карточка в Админ-чат
  ┌──────────────────────────────────────┐
  │ 📥 ЗАЯВКА НА ПОПОЛНЕНИЕ #00123       │
  │ 👤 @username (telegram_id)           │
  │ 🆔 ID 1xBet: 12345678               │

  │ [❌ Отклонить: Нет оплаты]           │

  ✅ Подтверждено → «Ваш баланс 1xBet пополнен!»
  ❌ Отклонено   → «Заявка отклонена: <причина>»

**Deeplink-переходы в банк (Шаг 5)**

Кнопка «Оплатить в ...» открывает банковское приложение напрямую на мобильном. Если deeplink не поддерживается — кнопка отсутствует, пользователь переводит вручную.

| Банк | Схема |
|---|---|
| MBank | `mbank://` |
| Bakai Bank | `bakaibank://` |
| O!Bank | `obank://` |
| DemirBank | `demirbank://` |
| Optima, MegaPay, Simbank | без deeplink |

## Структура проекта

```
1xbet-telegram-bot/
├── bot.py                  # Точка входа: регистрация роутеров, запуск polling
├── config.py               # Pydantic Settings: BOT_TOKEN, ADMIN_CHAT_ID, лимиты
├── keyboards/
│   ├── main.py             # Главное меню (ReplyKeyboard) + выбор языка
│   ├── banks.py            # Выбор банка + подтверждение ID (InlineKeyboard)
│   ├── captcha.py          # Капча-сетка (InlineKeyboard)
│   └── admin.py            # Кнопки оператора (InlineKeyboard)
├── handlers/
│   ├── start.py            # /start, выбор языка, главное меню, правила
│   ├── topup.py            # FSM сцена пополнения (все шаги)
│   ├── withdraw.py         # FSM сцена вывода (все шаги)
│   └── admin.py            # Callback-хендлеры кнопок оператора
├── states/
│   ├── topup.py            # StatesGroup для пополнения
│   └── withdraw.py         # StatesGroup для вывода
├── middlewares/
│   └── i18n.py             # Определение языка из FSMContext, подстановка текстов
├── locales/
│   ├── ru.py               # Словарь текстов RU
│   ├── en.py               # Словарь текстов EN
│   └── kg.py               # Словарь текстов KG
├── utils/
│   ├── deeplinks.py        # Схемы deeplink для банков
│   ├── validators.py       # Проверка ID (8-9 цифр), суммы (100-100000)
│   └── order.py            # Генерация order_id
├── .env                    # Секреты (не коммитить!)
├── .env.example
├── requirements.txt
└── README.md
```

## Машина состояний (FSM)

**Пополнение:**
```
captcha → enter_id → confirm_id → enter_amount → select_bank → await_receipt → DONE
```

**Вывод:**
```
captcha → upload_qr → enter_id → confirm_id → enter_withdraw_code → DONE
```

## Правила для пользователей

| Параметр | Значение |
|---|---|
